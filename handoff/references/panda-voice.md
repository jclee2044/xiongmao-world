# Panda voice

The user selected audition A, light, nasal and playful, on 2026-10-10. Panda uses Kokoro Mandarin speaker zm_009 (index 58), with the exact audition effect in `scripts/synthesize-neural.py`: Rubber Band pitch 1.155 and tempo 1.02, EQ +4 dB at 1250 Hz (Q 1.2), EQ -2 dB at 280 Hz (Q 1), and limiter 0.92. Slow playback adds pitch-preserving `atempo=0.8` after those effects.

`public/data/voices.js` defines Panda's separate `pandaVoiceProfile`. His hint speaker button, automatically spoken Ask Panda examples, and coaching replay select the `panda` ID. Native device voices cannot replace him. He shares the existing Kokoro model and sherpa-onnx Python environment with NPC speech. FFmpeg with the Rubber Band filter must be available on PATH. No remote synthesis service is used.

`server/panda-speech.js` serializes Panda synthesis and deduplicates identical in-flight requests. Generated WAVs are cached under ignored `data/panda-speech`; the key includes text, contextual pronunciation, speed, speaker and effect version. Changing those values invalidates the previous audio. Panda requests use a separate queue from NPC requests. Every fresh line still incurs local Kokoro generation latency, while cached replays avoid synthesis. No persistent Qwen worker or extra model environment remains.

The former Qwen TTS scripts, requirements file, model weights, virtual environment, Python/bootstrap tooling, synthetic reference asset and old generated-line cache were removed at replacement. The separate Ollama Qwen dialogue model remains in use and is unrelated to speech.

Validate using `node scripts/browser-panda-voice.js` (normal/slow WAV decoding, cache replay, hint/coaching routing) and `node scripts/browser-voices.js` (NPC speech and cast routing). Both require permission to bind a localhost test server. `/api/health` reports `kokoro-light-nasal-playful` and Panda speech responses use `X-Speech-Engine: kokoro`.

Verified on 2026-10-10: all twelve NPC profiles produced normal/slow WAVs decoded by Chromium; fourteen phone conversation/replay cases passed, including children, the bamboo worker, shared sprites and the reader's older portrait. Panda normal/slow playback and hint/coaching/replay routing passed. Production `/api/health` reports the Kokoro identity; fresh Panda intro and bank samples took 4.49 and 3.51 seconds, while cached replays took 6 and 3 ms. Both female speakers returned valid live WAVs. Local Whisper recognized the full bank sentence after Panda's effect. Pronunciation token checks cover all three installed neural lexicons; these checks do not prove every spoken tone. Targeted speech, pronunciation, family, API and base tests passed, as did JavaScript syntax checks. Qwen TTS removal was verified, reclaiming roughly 10 GB.
