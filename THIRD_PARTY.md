# Sources and runtime components

- Five handoff images: supplied by the user; PNGs described in the handoff as AI-generated. The original photograph defines the toy's identity. The candidate Panda is used unchanged as a sprite. PWA icons are standard size preparations of that sprite.
- Versions 0.2.0–0.4.0 painted environments and character cutouts: generated/edited with the built-in image-generation tool from the user's supplied Suzhou references. Canal Lane's background preserves the third reference's composition, with its people, animals and UI removed so characters can move independently. Reusable scenery, home, neighbors, walking poses, varied shops, landmark interpretations, animals and three room interiors follow its style. See [art/ASSETS.md](art/ASSETS.md) for output paths, exact prompt sets and lossless WebP encoding. No remote art-generation service runs inside the game.
- Background recording: **Asia — FSM Team**, [artist-authorized track/download page](https://www.free-stock-music.com/fsm-team-asia.html), [artist confirmation](https://fsmteam.bandcamp.com/track/asia), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Music by https://www.free-stock-music.com. Bundled locally as `public/assets/audio/asia-fsm-team.mp3`; transcoded from 320 to 160 kbps for size, with credit in Settings and MP3 metadata. This is an Asian-inspired chill-hop/lo-fi recording, not a claim of authentic traditional Chinese composition. Retain [ATTRIBUTION.md](public/assets/audio/ATTRIBUTION.md) and [CC-BY-4.0.txt](public/assets/audio/CC-BY-4.0.txt) with distributions. The original local procedural pentatonic score remains a fallback.
- Indoor recording: **Asian Music – Magical Dream — Sonican**, [Pixabay track and download](https://pixabay.com/music/china-asian-music-magical-dream-321895/), [Pixabay Content License](https://pixabay.com/service/license-summary/). Bundled locally as `public/assets/audio/sonican-asian-music-magical-dream.mp3` and credited in Settings. The track page marks it Content ID registered. See [ATTRIBUTION.md](public/assets/audio/ATTRIBUTION.md) for the exact source and checksum.
- Cultural descriptions: short original paraphrases checked on 2026-10-05 against Suzhou municipal-government pages and UNESCO's Classical Gardens of Suzhou entry. Version 0.5.0 adds [Lantern Festival riddles](https://www.suzhou.gov.cn/2025ndzt/xwbd/202502/0ba3f9fe64c644208f1688a196388e02.shtml) and [Suzhou embroidery with colored silk thread](https://english.suzhou.gov.cn/szsenglish/News/202510/c12f98a0f7d1481aba7d1e46757368bc.shtml). The beginner riddles and color designs are original game content, and shopping prices are fictional practice values. Exact links accompany each entry in `public/data/culture.js` and in the game. Generated landmark art is a condensed game interpretation, not a technical replica or navigable tourist map.
- Qwen3 4B, Q4_K_M: downloaded through Ollama's model registry, Apache-2.0 model license. https://ollama.com/library/qwen3 and https://huggingface.co/Qwen/Qwen3-4B. Dialogue generation runs on the CPU on this PC. Qwen3 1.7B failed the first quality gate; it is retained as a diagnostic download, not selected.
- Ollama 0.33.3: MIT; package from the configured Omarchy repository, installed under `tools/ollama/`. Model downloads are digest-verified by Ollama. Its runtime creates its normal per-user identity key in `~/.ollama/`; game state and models remain under project `data/`. Cloud inference disabled.
- eSpeak NG 1.52.0: GPL-3.0-or-later; pcaudiolib 1.3 and libsonic 0.2.0 dependencies from the same repository, installed under `tools/speech/`. See https://github.com/espeak-ng/espeak-ng. Mandarin is synthesized on demand; no prerecorded dialogue is served. This is a basic robotic voice and needs learner evaluation.
- pinyin-pro 3.29.4: MIT; https://github.com/zh-lx/pinyin-pro. Dictionary-based pinyin, not language-model spelling. Phrase-specific pronunciation and generated Chinese still need content review.
- Playwright 1.63.0: Apache-2.0; development-only automated browser tests against system Chromium.
- Piper Huayan was inspected but not installed: its specific model card lists an unknown dataset license. https://huggingface.co/rhasspy/piper-voices/blob/main/zh/zh_CN/huayan/medium/MODEL_CARD.

With `PROVIDER=gemini`, NPC dialogue and Panda coaching use Google's Gemini API (`gemini-3.5-flash-lite`) through the server. The API key remains in the local `.env` and is not sent to the browser. Ollama remains an optional local provider. No external font, analytics or third-party browser CDN is used.

## Version 0.6.0 additions

- Six new illustrated assets were generated with the built-in image tool. The user’s Panda/reference art supplied style and identity guidance. Files and exact prompts are recorded in [art/ASSETS.md](art/ASSETS.md). Real Suzhou photographs were viewed for research only; none are bundled as game assets.
- Local transcription: [faster-whisper 1.2.1](https://github.com/SYSTRAN/faster-whisper), MIT, with CTranslate2 CPU int8 and [PyAV 16.1.0](https://github.com/PyAV-Org/PyAV), BSD-3-Clause. Runtime environment is project-local under `tools/asr-venv`. PyAV’s bundled FFmpeg components retain their own licenses; preserve package notices when distributing that environment.
- [Systran/faster-whisper-base](https://huggingface.co/Systran/faster-whisper-base), MIT model card, revision `ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66`. This is a CTranslate2 conversion of Whisper base. The game loads it only from local `tools/whisper-base`; it never downloads models during play.
- Female local speech uses the existing eSpeak NG `cmn+f3` voice variant or a recognized local device voice. No new neural synthesis model was installed.
- Museum descriptions cover the Five Dynasties celadon lotus bowl, Northern Song Pearl Pillar and parallel street/canal layout. Exact primary sources and landscape/photo references appear in [SUZHOU_RESEARCH.md](SUZHOU_RESEARCH.md) and each exhibit’s game panel. The illustrations are interpretive, with that limitation displayed in the museum.

## Chinese dictionary and neural speech (0.7)

Copyright CC-CEDICT contributors; [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The archive retains its full license and source header. Dictionary-derived definitions remain under that license. Original game-specific learning explanations are stored separately.

- Local male model: `vits-zh-hf-fanchen-wnj` from [the sherpa maintainers' model release](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-zh-hf-fanchen-wnj.tar.bz2), provenance described in [their documentation](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html). Age-group and gender selection follows the [publisher’s metadata](https://huggingface.co/datasets/AISHELL/AISHELL-3/blob/main/spk-info.txt); see [casting research](handoff/references/voice-casting.md). [AISHELL's dataset metadata](https://huggingface.co/datasets/AISHELL/AISHELL-3) lists Apache-2.0.

## Old HSK vocabulary

`public/data/hsk-vocabulary.js` contains vocabulary labels from Chinese Testing International’s [official HSK vocabulary list (2015)](https://old.chinesetest.cn/userfiles/file/HSK/HSK-2015.xlsx), retrieved 2026-10-08. Levels 1–3 guide the general Chinese vocabulary; levels 4–6 identify advanced compounds. An explicit list of everyday game words supplements that guide, including familiar place names such as 书店. Parenthetical grammatical labels are removed and paired conjunctions are split into their component words. These are vocabulary facts, without the workbook’s presentation or explanatory text. This is the older six-level HSK system, not the newer HSK 3.0 standard.
